# پروژه: راه‌اندازی سایت وردپرسی (نسخه‌ی MVP یک‌هفته‌ای)

## ۱. تصمیمات معماری نهایی

- **پلتفرم:** وردپرس self-hosted (نه Elementor، نه هدلس، نه استاتیک خالص)
- **لایه‌ی طراحی/ادیت:** بلاک‌های سفارشی ACF (نه بلاک بومی React — کم‌دردسرتر برای نگهداری)
- **محیط توسعه:** لوکال (Local/wp-env روی سیستم کاربر) + گیت، قبل از هر چیزی روی هاست زنده
- **ابزار اجرا:** Claude Code (نصب‌شده، آماده) برای فاز ساخت؛ Cowork/این چت برای فاز محتوا و طراحی
- **مستندسازی:** فایل `CLAUDE.md` در ریشه‌ی ریپازیتوری برای معماری/قوانین/لیست بلاک‌ها — کاهش خطا و مصرف توکن در سشن‌های بعدی
- **کنترل نسخه:** commit جدا بعد از هر بلاک تکمیل‌شده

## ۲. وضعیت منابع (تایید‌شده)

| مورد | وضعیت |
|---|---|
| دامنه و هاست | آماده و فعال |
| لوگو | موجود |
| پالت رنگ / فونت | طراحی شد (از روی لوگو) — تایید شد |
| متن صفحات | نوشته شد — تایید شد به‌عنوان v1 |
| عکس محصول/خدمات | ندارد — فعلاً استوک/جایگزین، بعداً تعویض بدون دست‌زدن به کد |
| Claude Code | نصب و آماده |

## ۳. اسکوپ نسخه‌ی اول (MVP)

۴ صفحه‌ی اصلی، انیمیشن ساده و مؤثر (نه پرجزئیات):
1. لندینگ/صفحه‌ی اصلی
2. درباره‌ما
3. تماس با ما (فرم تماس کارکردی)
4. تمپلیت محصول/خدمت (یک الگوی تکرارپذیر)

خارج از اسکوپ v1 (برای فاز ۲ بعد از لانچ): بلاگ، انیمیشن‌های پیشرفته‌تر، چندزبانگی، عکس‌های واقعی نهایی.

## ۴. برنامه‌ی زمانی (۷ روز)

| روز | کار | محل انجام | وضعیت |
|---|---|---|---|
| ۱ | نگارش محتوای هر صفحه + پالت رنگ/فونت از روی لوگو + طرح HTML هر صفحه برای تایید | Cowork (این چت) | ✅ تایید شد (v1، قابل ادیت بخش‌به‌بخش بعداً) |
| ۲ | راه‌اندازی محیط لوکال وردپرس + ریپازیتوری گیت + `CLAUDE.md` | Claude Code | در حال شروع |
| ۳-۴ | ساخت بلاک‌های ACF طبق اسپک (تست محلی بعد از هر بلاک) | Claude Code | — |
| ۵ | تزریق محتوای نهایی و عکس‌های جایگزین + بازبینی ریسپانسیو/فرم | Claude Code | — |
| ۶ | انتقال فایل‌ها و دیتابیس به هاست زنده + SSL | Claude Code | — |
| ۷ | تست نهایی روی سایت زنده + پابلیش + بافر رفع باگ | Claude Code | — |

## ۵. موارد باز (بلاک‌کننده‌ی فازهای بعدی)

- [ ] تلفن، ایمیل، آدرس دقیق دفتر/انبار (لازم برای صفحه تماس و فوتر)
- [ ] نظرات مشتریان واقعی (حداقل ۲-۳ مورد، فعلاً جای‌گیر)
- [ ] تعداد سال فعالیت / تعداد مشتریان دقیق (برای بخش اعتمادسازی)
- [ ] لیست دقیق دسته‌بندی محصولات و چند نمونه محصول واقعی برای صفحه محصول

## ۶. ریسک‌های شناخته‌شده

- محتوای صفر یعنی سرعت تایید کاربر گلوگاه اصلیه، نه سرعت کدنویسی
- عکس‌های استوک باید هماهنگ با برند انتخاب بشن تا حس "جایگزین موقت" رو ندن
- در صورت تاخیر در تایید هر مرحله، کل زنجیره یک روز عقب می‌افته
